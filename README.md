# Macaptcha 🧩 (Math Captcha)

**Macaptcha** — это супер-легкая, минималистичная математическая капча, созданная для быстрой интеграции на любые сайты. Она работает внутри изолированного `iframe` через **GitHub Pages**, не нагружает ваш сайт и сообщает основному скрипту об успешном прохождении через безопасный механизм `postMessage`.

---

## ✨ Особенности
- **Вес < 2 КБ:** Никаких тяжелых библиотек или фреймворков.
- **Изоляция:** Работает в `iframe`, стили капчи не ломают верстку вашего основного сайта.
- **Защита от копирования:** Текст примера защищен от выделения (`user-select: none`), что усложняет жизнь простейшим парсерам.
- **Гибкость:** Вы можете повесить абсолютно любое JS-действие на успешное прохождение (открытие меню, разблокировка кнопки отправки формы, редирект).

---

## 🚀 Быстрый старт (Интеграция на сайт)

Чтобы добавить **Macaptcha** на свой сайт, вам нужно вставить всего два небольших блока кода: `iframe` и JS-слушатель событий.

### 1. HTML (Встраивание капчи и скрытого элемента)
Разместите этот код там, где должна отображаться капча.

```html
<!-- Контейнер капчи -->
<iframe 
    src="https://timoniki.github.io/macaptcha" 
    width="220" 
    height="45" 
    frameborder="0" 
    scrolling="no">
</iframe>

<!-- Элемент, который откроется после прохождения капчи (например, меню) -->
<div id="secret-menu" style="display: none; margin-top: 15px;">
    <h3>🎉 Доступ открыт!</h3>
    <p>Теперь вам доступны секретные функции меню.</p>
</div>

### 2. JavaScript (Обработка действия)
Добавьте этот скрипт перед закрывающим тегом `</body>`, чтобы поймать сигнал от капчи и выполнить действие:

```javascript
window.addEventListener('message', function(event) {
    // Безопасность: проверяем, что сообщение пришло именно от вашего GitHub Pages
    if (event.origin !== 'https://timoniki.github.io/macaptcha') return;

    // Проверяем тип события
    if (event.data.event === 'captcha_passed') {
        
        // ДЕЙСТВИЕ: Показываем скрытое меню
        document.getElementById('secret-menu').style.display = 'block';
        
        // Здесь может быть любое другое действие, например:
        // document.getElementById('submit-btn').disabled = false; // Разблокировать кнопку
    }
});
```

## 🛠️ Как развернуть проект у себя

Если вы хотите изменить дизайн капчи или логику генерации примеров:

1. Склонируйте этот репозиторий.
2. Откройте `index.html` и отредактируйте стили или JS-код под свои нужды.
3. Зайдите в настройки вашего репозитория на GitHub: **Settings** -> **Pages**.
4. В разделе **Build and deployment** выберите ветку `main` (или `master`) и папку `/ (root)`, затем нажмите **Save**.
5. Через 1-2 минуты ваша капча будет доступна по адресу: `https://github.io/имя-репозитория/`.

## 🔒 Безопасность и ограничения
Данная капча является **клиентской** (Client-side). Она идеально подходит для защиты от простых спам-ботов, кликеров или для скрытия элементов интерфейса от случайных нажатий. 

*Примечание: Так как проверка ответа происходит на стороне браузера (в JS), продвинутый программист сможет обойти её, изучив исходный код страницы. Для полноценной защиты критически важных данных (например, платежей) рекомендуется использовать серверную валидацию.*
